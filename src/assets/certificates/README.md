# Certificates Assets Directory (`src/assets/certificates`)

If you prefer bundling images via Vite/Webpack import statements (like in `Projects.jsx`), you can also place certificate images here:

```
w:\portfolio\src\assets\certificates\
```

### Recommendation:
For easiest drop-in usage without needing code imports, place your certificate files in:
```
public/images/certificates/
```
and link them directly in `src/data/achievements.js` with `'/images/certificates/filename.jpg'`.
